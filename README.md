# 🧠 Resume Analyzer & Job Match Bot

An AI-powered app that compares a candidate's resume with a job description and returns a match score, identifies skill gaps, and generates insights using GPT.

## 📌 Overview

This project helps:
- Job seekers optimize their resumes
- Recruiters quickly evaluate resume-job fit
- Users get actionable GPT-based insights about improvements

## 🚀 Features

- Upload **resume + job description**
- Extracts text from PDFs
- GPT-generated **match analysis** and **fit score**
- Lists **missing, matched, and suggested skills**
- Clean UI with intuitive result sections

## 🛠 Tech Stack

- Streamlit
- OpenAI API (GPT-4)
- LangChain
- PyPDF2
- Pandas

## 📦 Installation

```bash
pip install -r requirements.txt
streamlit run app.py
